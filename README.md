# Lead-qualifying agent — демо-проект

ИИ-агент для риелтора: принимает заявку покупателя в свободной форме (форма заявки, WhatsApp, e-mail), извлекает критерии, квалифицирует лида и подбирает лучшие листинги из инвентаря. Работает полностью офлайн, без ключей и сетевых вызовов.

## Возможности

- **Экстракция критериев** из свободного текста: бюджет, спальни, ванные, тип объекта, районы, срочность, профиль покупателя (семья / впервые покупает / инвестор), must-have и nice-to-have фичи.
- **Объяснимая квалификация лида**: балл 0–100 и вердикт HOT / WARM / COLD с человеком читаемыми весами.
- **Матчинг листингов**: жёсткие фильтры, затем ранжирование; к каждому матчу прилагаются причины совпадения (reasons).
- **Агентские заметки**: если инвентарь пустой или тесный, если пул кандидатов обрезан, если ни один кандидат не закрывает все must-have — агент честно сообщает об этом.
- **Масштаб**: синтетический стор на 1 000 000 листингов строится из фиксированного seed за доли секунды и ищет за единицы миллисекунд. Детерминированный: один seed — всегда один и тот же инвентарь.
- **LLM-хук**: `extract_llm()` — точка подключения LLM-экстрактора. В текущей версии это заглушка: при отсутствии `OPENAI_API_KEY` (или всегда, по сути) пайплайн работает через rule-based экстрактор. Автопереключения на модель в коде нет — реальный вызов модели нужно добавить в тело функции.

## Быстрый старт

Нужен Python 3.10+.

```bash
python -m venv venv
source venv/bin/activate          # Mac/Linux
# venv\Scripts\Activate.ps1      # Windows PowerShell

pip install -r requirements.txt
pytest -v                          # 49 тестов
```

### Streamlit UI (основной экран демо)

```bash
streamlit run app/ui.py
```

Откроется `http://localhost:8501`. В сайдбаре выбирается стор (демо на 20 листингов или синтетика на 1M), есть готовые сэмплы заявок. На каждую заявку агент показывает балл, вердикт, извлечённые критерии и топ-3 матча с причинами.

### API

```bash
uvicorn app.main:app --reload
```

- `GET /health` — статус и размер инвентаря.
- `POST /lead` — тело `{"inquiry": "<текст заявки>"}`; ответ — карточка лида с вердиктом, критериями, топ-3 матчами и заметками агента. Пустая заявка возвращает HTTP 400.
- `GET /listings?limit=20` — первые листинги инвентаря.
- Swagger UI: `http://localhost:8000/docs`.

Пример:

```bash
curl -X POST http://localhost:8000/lead \
  -H "Content-Type: application/json" \
  -d '{"inquiry": "Family of 4, budget 550k, need 3BR in Austin, good schools"}'
```

### Бенчмарк

```bash
python bench.py
```

Строит 1M листингов и меряет время поиска, память и детерминизм (rebuild по тому же seed даёт идентичный инвентарь). Ориентир: сборка ~0.1 с, поиск 4–10 мс, память ~27 MB сверх базовой.

## Структура репозитория

```
app/
  data.py        # константы: фичи, типы, регионы + 20 демо-листингов
  pipeline.py    # экстракция, квалификация, скоринг, пайплайн
  generator.py   # синтетический стор на 1M листингов (numpy, seed)
  main.py        # FastAPI: /health, /lead, /listings
  ui.py          # Streamlit-консоль
tests/
  test_pipeline.py
bench.py         # бенчмарк большого стора
requirements.txt
PROJECT.md       # подробные заметки о дизайне
```

## Замечания по качеству

- Все ответы детерминированы — видео-демо и повторные прогоны дают одинаковые результаты.
- Веса скоринга задокументированы в PROJECT.md и покрыты тестами; каждое совпадение объяснимо построчно.
